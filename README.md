# Mòlì 茉莉 — китайский язык играючи

Веб-приложение для изучения китайского (HSK 1) в духе Duolingo с дизайном уровня Awwwards.

## Возможности

- **Путь обучения** — 10 юнитов, 56 уроков, 129 слов и 60 фраз HSK 1 (тесты в конце юнитов).
- **8 типов заданий** — новое слово, выбор перевода, аудирование, выбор тона, пары, сборка предложения, пропуск, написание иероглифа по чертам.
- **Геймификация** — XP, дневная цель, серия дней с заморозками, сердца, кристаллы, достижения, недельная лига.
- **Интервальные повторения (SRS)** — умное повторение, работа над ошибками, аудирование, каллиграфия, фразы.
- **Тоны** — интерактивная таблица тонов и тренажёр «угадай тон».
- **Иероглифы** — словарь с поиском (ханьцзы / пиньинь / перевод), анимацией порядка черт и режимом письма.
- **Озвучка** — Web Speech API (`zh-CN`), обычная и медленная скорость.
- Прогресс хранится в `localStorage` — бэкенд не нужен.

## Стек

Vite · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · Lenis · Zustand · hanzi-writer · canvas-confetti

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run lint
```

Деплой — любой статический хостинг (Vercel/Netlify: SPA-редиректы уже настроены в `vercel.json` и `public/_redirects`).

> Для озвучки нужен браузер с китайским голосом (Chrome, Edge, Safari).
